## 1. Стандарт размеров матриц фигур

**Правило:** ВСЕ 4 вращения каждой фигуры имеют ОДИНАКОВЫЙ размер матрицы.

| Фигура | Размер матрицы | Примечание |
|--------|----------------|------------|
| I | 4×4 | Во всех 4 вращениях |
| O | 2×2 | Во всех 4 вращениях |
| T | 3×3 | Во всех 4 вращениях |
| S | 3×3 | Во всех 4 вращениях |
| Z | 3×3 | Во всех 4 вращениях |
| J | 3×3 | Во всех 4 вращениях |
| L | 3×3 | Во всех 4 вращениях |

**Почему:** Несогласованные размеры (3×2, 3×1 и т.д.) ломали `isValid()` и рендеринг.

## 3. Wall Kicks (SRS-подобная система)

**В GameEngine.rotate():**

```javascript
const kicks = [
  { x: 0, y: 0 },      // 0: без смещения
  { x: 0, y: -1 },     // 1: вверх
  { x: -1, y: 0 },     // 2: влево
  { x: 1, y: 0 },      // 3: вправо
  { x: 0, y: 1 },      // 4: вниз
  { x: -1, y: -1 },    // 5: диагональ ↖
  { x: 1, y: -1 },     // 6: диагональ ↗
  { x: -1, y: 1 },     // 7: диагональ ↙
  { x: 1, y: 1 },      // 8: диагональ ↘
  { x: -2, y: 0 },     // 9: далеко влево
  { x: 2, y: 0 }       // 10: далеко вправо
];
```

**Логика:** Пробуем каждую kick-позицию по порядку. Первая, которая проходит `isValid()`, применяется.

**Порядок важен:** Проверяем по стандарту SRS (Super Rotation System).

## 4. Как работает вращение

```javascript
rotate(dir) {
  const newRot = ((this.rotation + dir) % 4 + 4) % 4;
  // newRot: (rotation + dir) mod 4, корректно обрабатывает отрицательные значения
  
  for (const kick of kicks) {
    const test = { x: this.currentPos.x + kick.x, y: this.currentPos.y + kick.y };
    if (this.isValid(test, newRot)) {
      this.rotation = newRot;
      this.currentPos = test;
      return;
    }
  }
  // Если ни одна kick не подошла — вращение отменяется (старое остаётся)
}
```

## 5. Verification (SRS/Tetris standard)

| Фигура | Rot 0 | Rot 1 | Rot 2 | Rot 3 |
|--------|-------|-------|-------|-------|
| I | 4×4 гориз. row 1 | 4×4 верт. col 1 | 4×4 гориз. row 2 | 4×4 верт. col 2 |
| O | 2×2 | 2×2 | 2×2 | 2×2 |
| T | ↓ | ← | ↑ | → |
| S | ↗ | ↙ | ↗ | ↙ |
| Z | ↘ | ↗ | ↘ | ↙ |
| J | ↖ | ↗ | → | ↘ |
| L | ↗ | ↖ | ← | ↘ |

**Критерий верификации:** Каждая из 4-х матриц должна быть истинным 90°-поворотом предыдущей. Все заполнённые клетки — ровно 4 (для тетромино).
