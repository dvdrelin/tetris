# Spectator / Observer Mode — Neon Tetris

> Дополнение к GDD: как работают зрители в комнате матча.

---

## 1. Роли и доступ

| Роль | Может присоединиться | Может писать в чат | Права |
|------|:---:|:---:|-------|
| Игрок | До старта / во время | Да (в режиме быстрых фраз) | Полный геймплей |
| Зритель | В любое время, если комната не `🔒` | Только чтение | Просмотр полей всех игроков |
| Хост | Меняет режим комнаты, кикает | Да | Админ комнаты |

**Зритель может присоединиться:**
- До матча (ждёт в лобби, видит Ready Check).
- Во время матча (подключается, видит текущую игру в реальном времени).
- После матча (видит экран результатов и историю чата).

## 2. Что видит зритель

```
┌──────────────────────────────────────┐
│    🎥 РЕЖИМ НАБЛЮДАТЕЛЯ              │
│                                      │
│  ┌──────────┐ ┌──────────┐           │
│  │ Игрок A  │ │ Игрок B  │           │
│  │ (стакан) │ │ (стакан) │           │
│  │  12 очк. │ │   8 очк. │           │
│  └──────────┘ └──────────┘           │
│  ┌──────────┐ ┌──────────┐           │
│  │ Игрок C  │ │ Игрок D  │           │
│  │ (стакан) │ │ (стакан) │           │
│  │  15 очк. │ │   5 очк. │           │
│  └──────────┘ └──────────┘           │
│                                      │
│  📊 Лидер: C ⚡ Линии: 15            │
│  ⌛ 02:34 до конца                    │
│                                      │
│  [Чат (только чтение)]               │
│  ┌─────────────────────────────┐     │
│  │ A: GG!                       │     │
│  │ B: wp                        │     │
│  └─────────────────────────────┘     │
└──────────────────────────────────────┘
```

**Ключевые элементы:**
1. **Все 4 стакана** в сетке 2×2 (или 1×4 на мобильном).
2. **Индикатор очереди мусора** у каждого стакана (те же анимации, что у игрока).
3. **Лидерборд** (очки) — всегда виден.
4. **Чат** — только чтение, кнопка отправки скрыта.
5. **Кнопка «Выйти»** — зритель может покинуть в любой момент.

## 3. Протокол подключения зрителя

```mermaid
sequenceDiagram
    participant Z as Зритель
    participant S as Сервер

    Z->>S: spectator_join { room_id }
    S->>Z: spectator_welcome {
        players: [
            { id: "Neo#2312", score: 12, board_state: "base64...", active: true },
            { id: "Z-Tet#819", score: 8, board_state: "base64...", active: true },
            { id: "Block#001", score: 15, board_state: "base64...", active: true },
            { id: "Ice#442", score: 5, board_state: "base64...", active: false, eliminated: true }
        ],
        chat_history: [ ... ],
        game_phase: "in_progress",
        time_remaining_sec: 154
    }
    Note over Z: После этого сервер шлёт те же события, что и игрокам,
    Note over Z: кроме piece_lock (зритель не может взаимодействовать).
    
    loop Каждый игровой тик
        S->>Z: board_update { player: A, board: "base64...", score: 13 }
        S->>Z: board_update { player: B, board: "base64...", score: 9 }
        S->>Z: attack_send { from: A, to: B, lines: 4, delay_ms: 900 }
        S->>Z: attack_nullify { player: B, nullified: 2, remaining: 2 }
    end
    
    Z->>S: spectator_leave { room_id }
    S->>Z: spectator_left { room_id }
```

**Важно:** Зритель получает **полную копию потоковых событий** (board_update, attack_send, attack_nullify, player_eliminated, game_over), но не может отправлять piece_lock или влиять на игру.

## 4. Ограничения для зрителей

| Правило | Описание |
|---------|----------|
| Задержка | Зритель может получать данные с задержкой +1 тик (100 мс) от реального времени, чтобы не создавать нагрузку real-time |
| Кол-во зрителей | Не более 20 на комнату (предотвращает DoS) |
| Чат read-only | Зритель не может отправлять сообщения в комнату |
| Замок | Если комната 🔒, зритель не может присоединиться (даже если знает room_id) |
| Стрим-режим | Зрители не получают seed — только визуальное состояние поля (board_state). Это исключает спуфинг игрока через зрительский клиент |
| Пул соединений | Зрители подключаются через отдельный WebSocket-эндпоинт `/ws/spectate/:room_id`, не смешиваясь с игровыми соединениями |

## 5. UI-элементы для мобильного зрителя (альбомный режим)

На мобильных устройствах экран зрителя автоматически переключается в **карусельный режим**:

```
┌────────────────────┐
│  [A] [B] [C] [D]   │ ← табы игроков
├────────────────────┤
│                    │
│   ┌────────────┐   │
│   │  Стакан A  │   │
│   │  12 очк.   │   │
│   └────────────┘   │
│                    │
│ Очередь мусора A   │
│ [█] [█] [ ] [ ]    │
│                    │
│ Чат (последние 2)  │
│ A: GG              │
│ B: wp              │
└────────────────────┘
```

- Зритель тапает по табу игрока, чтобы увидеть его стакан в крупном размере.
- Лидерборд — выпадающая панель сверху.
- Чат — свернутая строка снизу.
