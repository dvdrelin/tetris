# 🎮 Neon Tetris

Красочный, яркий аркадный Тетрис с неоновой стилистикой.

## 🎯 Особенности

- **Неоновая графика**: Светящиеся блоки, частицы, анимированный фон
- **2 режима**: Аркадный (с авто-дропом и комбо-системой) и Хардкор
- **7-Bag randomizer**: Честное распределение фигур
- **Ghost piece**: Показывает место падения
- **Комбо-система**: Множитель очков за последовательные очистки линий
- **Таблица рекордов**: Сохранение лучших результатов
- **Touch-управление**: Поддержка свайпов на мобильных

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| ← → / A D | Движение |
| ↑ / W X Z C | Вращение (CW) |
| Q | Вращение (CCW) |
| ↓ / S | Soft Drop |
| Space | Hard Drop |
| P / Esc | Пауза |
| Enter | Рестарт после Game Over |
| S | Сохранить рекорд |

## 🚀 Запуск

### Быстрый старт (без сборки):
```
Просто откройте index.html в браузере
```

### Полный стек:
```bash
npm install
npm run dev          # Запуск dev-сервера
```

## 🏗 Архитектура

- **CQRS**: Commands (Start, Move, Rotate, Drop) / Queries (GetState)
- **OOP**: GameEngine, BoardManager, PieceFactory
- **SOLID**: Каждый класс имеет одну ответственность
